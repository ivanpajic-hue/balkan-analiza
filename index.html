Čitanje ide preko JSONP (bez CORS problema). Push proverava rezultat automatskim povlačenjem. Token/URL se drže lokalno; ništa tajno nije u kodu.
Održavanje lokalnog keša
„Obriši keš" briše lokalno sačuvane podatke (pri sledećem povlačenju iz Sheets baza je izvor istine). „Fabrički" vraća originalne bilanse 2025/2026 iz alata.

Apps Script — kopiraj u Google Sheet

  1. Google Sheet → Extensions → Apps Script
  2. Obriši sve i nalepi kod ispod; postavi API_TOKEN
  3. Deploy → New deployment → Web app (Execute as: Me · Access: Anyone)
  4. Kopiraj Web app URL (…/exec) ovde levo i klikni „Sačuvaj vezu"
  5. Ne klikći „Run" na doGet/doPost (baca grešku „code 20" jer nema podataka zahteva). Za proveru pokreni funkciju test, a vezu proveri dugmetom „Test veze".
